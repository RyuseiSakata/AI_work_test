# Antigravity WordPress自動投稿システム 🚀

このシステムは、外部のAI API（Make/OpenAIなど）を使わず、**Antigravity自身がAIとなり、記事作成・画像生成・WordPressへの入稿を全自動で行う**ためのツール群です。

## 📁 ファイル構成

*   `wp_auto_poster.py`: Antigravityが呼び出して、WordPressのAPIに記事と画像をアップロードするためのPythonプログラム。
*   `add_text.py`: 生成した画像に対して、タイトルや詳細情報などのテキストを自動で合成（文字入れ）するためのPythonプログラム。
*   `.env.example`: パスワード設定ファイルのひな形。

---

## ⚙️ 初回セットアップ手順

パスワードなどを安全に管理するため、設定ファイルを作成します。

1. このフォルダの中にある `.env.example` というファイルをコピーし、名前を **`.env`**（ドットエンブ）に変更してください。
2. 作成した `.env` ファイルをテキストエディタで開き、以下の情報をあなたの環境に合わせて書き換えて保存します。

```text
WP_URL=https://your-domain.com
WP_USER=admin
WP_APP_PASS=xxxx xxxx xxxx xxxx xxxx xxxx
```

※ `WP_APP_PASS` はWordPress管理画面の「ユーザー」＞「プロフィール」の一番下から発行できるアプリケーションパスワードです。

## 🧑‍💻 使い方（Antigravityへの依頼方法）

画像生成からPython (`add_text.py`) を用いたテキスト合成（文字入れ）までを自動化する方法です。

### 画像生成＋Pythonでの文字入れ自動化 🎨

イベント用の画像生成と、指定したテキスト情報の画像への合成（Pythonスクリプト使用）をAntigravityに一括で依頼するためのテンプレートです。見切れ防止や左揃えなどの自動調整が適用されます。

**【依頼用テンプレート】**
以下のテンプレートの `【 】` の部分をイベント内容に書き換えて送信してください。

> **以下の要件に従って、モデルハウス見学会用の画像生成と、指定したテキスト情報の画像への合成（Pythonスクリプト使用）を行ってください。**
> 
> **1. 画像生成の要件**
> 以下のヒントをもとに、指定枚数の画像を生成してください。（文字なしで生成すること）
> * 画像テーマ・テイスト: 【（例）シックなモデルハウス / ナチュラルテイストで明るいリビング など】
> * 必要な画像の枚数・種類: 【（例）以下の3種類を1枚ずつ生成：①外観画像、②W断熱の解説イラスト、③耐震性能の解説イラスト など】
> * 特徴: 高品質、写実的、プロの建築写真風
> 
> **2. テキスト情報（Pythonで画像に追加する内容）**
> 生成した画像に対して、Pythonスクリプト (`add_text.py`) を作成・更新し、以下のテキストを追加してください。
> * メインタイトル: 【（例）シックなモデルハウス見学会】
> * 詳細情報（箇条書き）: ※不要な画像には入れない
>   * 【日時：3月1日～3月20日】
>   * 【場所：東京都渋谷区】
>   * 【ターゲット：30代の子育て世帯】
>   * 【アピールポイント：W断熱、シックな外観、耐震性能】
> 
> **3. テキスト合成（Pythonスクリプト）のレイアウト指定**
> 以下のレイアウト制御を必ず実装してください。
> 1. 見切れ防止（自動縮小）: 幅が画像の横幅（90%）を超える場合は自動縮小。
> 2. 上下の余白: `textbbox` を用いてフォント特有の余白を計算し、文字が上下にはみ出さないように配置。
> 3. 詳細情報の左揃え: ブロック全体は中央配置、各行は左揃え。
> 4. 視認性の確保: タイトルには白フチ、または詳細情報の下に半透明の帯を敷くなど。

これらを送っていただければ、以下の処理を代行します。
1. プロンプトに沿った高品質な画像の生成
2. Pythonスクリプトの調整・実行 (`add_text.py`)
3. 生成した画像へのテキスト合成（ローカルフォルダへ保存）

## 🛠️ トラブルシューティング
*   **AIエージェントの操作が途中で止まる場合:** セキュリティ画像認証（CAPTCHA）などが出た場合は手動で突破し、再度エージェントに続きを指示してください。画像のアップロードがうまくいかない場合（ドラッグ＆ドロップ不可など）は、生成された画像をダウンロードして手動でアップロードしてください。
*   **「エラー: .envファイルに...」と出る場合:** (API入力時) `.env` ファイルが設定されているか確認してください。
*   **「ステータスコード: 403/401」と出る場合:** (API入力時) セキュリティによるAPI制限や、アプリケーションパスワードの間違いが原因です。AIエージェントモード（方法1）をお試しください。
