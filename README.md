# 🚀 Antigravity ブログ記事＆画像作成アシスタント

このフォルダには、Antigravity（AI）にお願いして**「魅力的なブログ記事の作成」**から**「アイキャッチ画像の生成と文字入れ」**までを全自動で行うためのツールが入っています。

完成した記事は、そのままWordPressの編集画面（ブロックエディタ）にコピペするだけ！非常に簡単です。

---

## 📁 中に入っているもの

*   `add_text.py`：生成された画像に対して、キレイに文字（タイトルなど）を合成・配置してくれるPythonプログラムです。
*   `wp_auto_poster.py` / `.env.example`：※現在使用していません（API自動投稿用の過去ファイルです）。

---

## 🎯 使い方（Antigravityへの依頼方法）

イベント情報を伝えるだけで、AIが記事本文の執筆、画像の生成、そして画像への文字入れまでを一括して行ってくれます。

### 📝 依頼ステップ

以下の【依頼用テンプレート】をコピーして、`【 】` の部分をご自身のイベント内容に書き換えてAntigravityにメッセージを送信してください。

---

### 📋 【依頼用テンプレート】（ここからコピー）

**以下の要件に従って、ブログ用の「記事作成」「画像生成」「画像への文字入れ」を一括で行ってください。**

#### 1. ブログ記事の作成 ✍️
以下の情報をもとに、読者が魅力を感じるような記事本文を作成してください。
※WordPressのブロックエディタにそのままコピペできるよう、適切な見出し（H2, H3など）や箇条書きを用いたMarkdown形式で出力してください。

*   **イベント名:** 【（例）春のモデルハウス見学会】
*   **開催日時:** 【（例）4月XX日(土)〜XX日(日)】
*   **場所:** 【（例）〇〇県〇〇市】
*   **ターゲット:** 【（例）30代の子育て世帯】
*   **アピールポイント:** 【（例）広い土間収納、家事動線、無垢材】

#### 2. 画像の生成 🖼️
記事の内容に合わせて、以下の画像を生成してください。（※画像内に直接文字は入れないでください）

*   **画像テーマ・雰囲気:** 【（例）ナチュラルテイストで明るいリビング】
*   **必要な画像の枚数と種類:** 【（例）以下の3種類を1枚ずつ：①外観画像、②断熱の解説イラスト、③内観画像】
*   **特徴:** 高品質、写実的、プロの建築写真風

#### 3. 画像への文字入れ自動化 🎨
生成された画像について、Pythonスクリプト (`add_text.py`) を更新・実行し、以下のテキストを追加して保存してください。

*   **メインタイトル:** 【（例）春のモデルハウス見学会】
*   **詳細情報（箇条書き）:** （※テキストを入れる必要のない画像には入れないでください）
    *   【日時：4月XX日〜XX日】
    *   【場所：〇〇県〇〇市】
    *   【ターゲット：30代向け】
    *   【特徴：家事動線、無垢材】

*   **レイアウトの必須条件:**
    1. タイトルが長すぎる場合は、画像幅の90%に収まるよう自動縮小（見切れ防止）。
    2. 文字が上下にはみ出さないように、フォントの余白を適切に計算。
    3. 詳細情報は、ブロック全体を中央に配置し、各行は左揃えにする。
    4. 視認性を高めるため、文字に白フチをつける、または半透明の帯を敷くなどの工夫をする。

### ✨ 依頼後の流れ

上記のテンプレートを送信すると、Antigravityが以下の作業をすべて代行します。

1.  Markdown形式での**ブログ記事全文**のテキスト出力
2.  指定されたテーマでの**ハイクオリティ画像の生成**
3.  生成された画像へのキレイな**タイトル文字合成**（`add_text.py`の自動実行・保存）

完了したら、**出力された記事テキストと、文字入れが完了した画像をそのままWordPressにコピペ・貼り付け**するだけで投稿準備が完了します！

---

## 🛠️ トラブルシューティング
*   **AIエージェントの操作が途中で止まる場合:** セキュリティ画像認証（CAPTCHA）などが出た場合は手動で突破し、再度エージェントに続きを指示してください。画像のアップロードがうまくいかない場合（ドラッグ＆ドロップ不可など）は、生成された画像をダウンロードして手動でアップロードしてください。
*   **「エラー: .envファイルに...」と出る場合:** (API入力時) `.env` ファイルが設定されているか確認してください。
*   **「ステータスコード: 403/401」と出る場合:** (API入力時) セキュリティによるAPI制限や、アプリケーションパスワードの間違いが原因です。AIエージェントモード（方法1）をお試しください。
